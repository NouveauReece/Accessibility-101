# 1.1 - Different Screen Readers

| Screen Reader | OS | Cost |
| -- | -- | -- |
| VoiceOver | macOS, iOS | Free (Apple Built-In) |
| NVDA | Windows | Free (3rd Party) |
| JAWS | Windows | $600-$2,000 (3rd Party) |
| Narrator | Windows | Free (Windows Built-In) |
| TalkBack | Android | Free (Android Built-In) |

## Turn On A Screen Reader

VoiceOver: `Cmd` + `F5`   
NVDA: `Ctrl` + `Alt` + `N`   
Windows Narrator: `Windows` + `Ctrl` + `Enter`

## Navigating a Page

VO = Voice Over Keys = `Ctrl` + `Opt`
